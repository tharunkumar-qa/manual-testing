# API Testing with Postman

This section contains my manual API testing practice using Postman.

## Topics Covered

- HTTP methods
- GET, POST, PUT, PATCH, DELETE
- Request and response validation
- Status code validation
- Headers
- Request body
- Response body
- Authentication
- Negative testing
- Basic API test scripts
- Test execution and reporting

## Tools

- Postman
- REST APIs

## Testing Approach

APIs are tested using positive and negative test scenarios.

The following are validated:

- HTTP status codes
- Response body
- Response headers
- Response time
- Request parameters
- Request payload
- Authentication behavior
