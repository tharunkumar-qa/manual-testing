# Manual Testing - Test Cases

## Login Test Cases

| TC ID | Test Scenario | Steps | Expected Result | Priority |
|---|---|---|---|---|
| TC-001 | Verify login with valid credentials | Enter valid username and password and click Login | User should be logged in successfully | High |
| TC-002 | Verify login with invalid password | Enter valid username and invalid password | Appropriate error message should be displayed | High |
| TC-003 | Verify login with blank fields | Leave username and password blank and click Login | Validation messages should be displayed | Medium |
| TC-004 | Verify password field masking | Enter password in the password field | Password should be masked | Medium |
| TC-005 | Verify logout functionality | Login and click Logout | User should be logged out successfully | High |
